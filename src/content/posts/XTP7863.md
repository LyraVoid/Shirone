GXTP7863 这个触摸板在我这里有时可用有时不可用，特别是在一次更新之后就几乎不可用

但最近，它在待机一段时间后又可用了

所以，我将解决方法分享出来

## 触摸板修复方法

### 手动修复

```bash
# 阶段1：直接重新绑定
echo i2c-GXTP7863:00 | sudo tee /sys/bus/i2c/drivers/i2c_hid_acpi/bind

# 阶段2：若无效，复位 I2C 控制器强制重新枚举
echo i2c_designware.0 | sudo tee /sys/bus/platform/drivers/i2c_designware/unbind
sleep 2
echo i2c_designware.0 | sudo tee /sys/bus/platform/drivers/i2c_designware/bind
```

### 开机自动恢复

把下面的脚本安装 `sudo install -Dm755 (此文件位置.sh) /usr/local/bin/touchpad-rebind.sh`

``` bash
set -u

I2C_NAME="i2c-GXTP7863:00"
I2C_HID_DRV="/sys/bus/i2c/drivers/i2c_hid_acpi"
I2C_HID_DEV="/sys/bus/i2c/devices/${I2C_NAME}"
DW_DRV="/sys/bus/platform/drivers/i2c_designware"
DW_DEV="i2c_designware.0"

log() { logger -t touchpad-rebind "$*"; echo "[touchpad-rebind] $*"; }

present() { grep -qs 'GXTP7863.*Touchpad' /proc/bus/input/devices; }

# ---------- 阶段 1：直接重新绑定驱动 ----------
for attempt in $(seq 1 10); do
    if present; then
        [ "$attempt" -gt 1 ] && log "触摸板已恢复（阶段1，第 ${attempt} 次）"
        exit 0
    fi

    if [ -e "${I2C_HID_DRV}/bind" ] && [ -d "${I2C_HID_DEV}" ]; then
        echo "${I2C_NAME}" > "${I2C_HID_DRV}/bind" 2>/dev/null
    fi
    sleep 1
done
present && exit 0

# ---------- 阶段 2：复位 I2C 控制器 ----------
if [ ! -e "${DW_DRV}/unbind" ]; then
    log "阶段1失败，且 ${DW_DRV}/unbind 不可用，无法复位控制器"
    exit 1
fi

for cycle in 1 2 3; do
    log "阶段1失败，复位 I2C 控制器 ${DW_DEV}（第 ${cycle} 次）"

    echo "${DW_DEV}" > "${DW_DRV}/unbind" 2>/dev/null
    sleep 2
    echo "${DW_DEV}" > "${DW_DRV}/bind" 2>/dev/null

    for _ in $(seq 1 8); do
        if present; then
            log "控制器复位后触摸板已恢复"
            exit 0
        fi
        sleep 1
    done
done

log "两种方式均未能启用触摸板，需要重启"
exit 1

```

再安装 `sudo install -Dm644 ~ (此文件位置.service) /etc/systemd/system/touchpad-rebind.service`
（来源 [Archlinux BBS](https://bbs.archlinux.org/viewtopic.php?pid=2302559)）

```service
[Unit]
Description=确保 Goodix GXTP7863 I2C-HID 触摸板在启动后可用
Documentation=https://bbs.archlinux.org/viewtopic.php?pid=2302559
After=multi-user.target
ConditionPathExists=/sys/bus/i2c/drivers/i2c_hid_acpi

[Service]
Type=oneshot
RemainAfterExit=yes
ExecStart=/usr/local/bin/touchpad-rebind.sh
TimeoutStartSec=40

[Install]
WantedBy=multi-user.target

```

## 根因的模块顺序修复

如果你是 Intel 用户的话可能  `intel_lpss_pci` 比 `pinctrl_tigerlake` 早加载，会让 `pinctrl_bind_pins()` 只能 defer 重试

这时候，就编辑`/etc/mkinitcpio.conf`，在`MODULES`改

```
MODULES=(pinctrl_tigerlake intel_lpss_pci i2c_hid_acpi i2c_hid hid_multitouch)
```

运行

``` bash
sudo mkinitcpio -P
```

重启之后，你的触摸板就可以使用了
